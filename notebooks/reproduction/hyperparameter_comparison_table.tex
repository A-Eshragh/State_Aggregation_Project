\textbf{Parameters that need confirmation.}
\begin{itemize}[leftmargin=1.5em,itemsep=2pt,topsep=2pt]
    \item Inventory \texttt{qp\_reg}: Table 2 gives $10^{-3}$, while the local reproduction recipe uses 50.
    \item Inventory Sketch $\rho$: Table 2 gives 0.1, while the local reproduction recipe uses 10.
    \item Cliff Sketch settings: Table 2 gives $K=8$ and row-keep ratio 0.2, while the from-scratch Table 3 recipe uses $K=4$ and row-keep ratio 0.1.
    \item Cliff SA loss weight: the local Appendix Table 3 reproduction uses 500, but this value is not clearly listed in Table 2.
    \item Cliff SA temperature: Table 2 gives $\tau=0.5$, while the local Table 3 recipe uses $\tau=2.0$ for $M=24$.
    \item Cliff aggregation sizes: Table 2 lists $\{10,20,30\}$, while Appendix Table 3 uses $\{6,12,24\}$.
\end{itemize}
